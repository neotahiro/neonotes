# Noenotes

A minimalist, distraction-free writing app. Next.js, TypeScript, Tailwind CSS, TipTap and Lucide.

Status: **step 4 of 7 (part 2)** — Google sign-in restricted to one account, folders, notes saved in this browser (IndexedDB). No Drive connection yet. See [docs/PLAN.md](docs/PLAN.md).

## Run it

```bash
npm install
npm run dev
```

Open http://localhost:3000.
