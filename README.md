# Noenotes

A minimalist, distraction-free writing app. Next.js, TypeScript, Tailwind CSS, TipTap and Lucide.

Status: **step 5 of 7 (part 1)** — Google sign-in restricted to one account, server-side Drive connection check, folders, notes saved in this browser (IndexedDB). Notes are not stored in Drive yet. See [docs/PLAN.md](docs/PLAN.md).

## Run it

```bash
npm install
npm run dev
```

Open http://localhost:3000.
