# Noenotes

A minimalist, distraction-free writing app. Next.js, TypeScript, Tailwind CSS, TipTap and Lucide.

Status: **step 4 of 7 (part 1)** — folders with multiple notes and moving, notes saved in this browser (IndexedDB). No sign-in or Drive connection yet. See [docs/PLAN.md](docs/PLAN.md).

## Run it

```bash
npm install
npm run dev
```

Open http://localhost:3000.
