# Noenotes

A minimalist, distraction-free writing app. Next.js, TypeScript, Tailwind CSS, TipTap and Lucide.

Status: **step 1 of 7** — interface with sample data. Nothing is saved yet, and there is no sign-in or Drive connection. See [docs/PLAN.md](docs/PLAN.md).

## Run it

```bash
npm install
npm run dev
```

Open http://localhost:3000.
